# Геометрия таблиц: изолированный прототип

18 октября 2026: PR 12–19 слиты в main, CI основной ветки прошёл.
Новая работа ведётся отдельно от основного QA-пайплайна.

## Что делает прототип

`inspect_page_tables` извлекает таблицы с линиями сетки из native PDF через
опциональный pdfplumber. Для каждой ячейки сохраняются исходный текст и прямоугольник
в PDF points с началом координат в левом верхнем углу страницы, а также размер
страницы и её номер. Это не символьные offsets существующего QA API.

`select_cell` находит единственное пересечение точной подписи строки в первом
столбце и точного заголовка в первой строке. Возвращает три источника: подпись,
заголовок, значение — каждый с координатами. Пробелы/переносы нормализуются
только при сравнении, текст доказательства сохраняется.

Пустые/объединённые ячейки (`None`) не заполняются значениями соседей. Несколько
совпадений приводят к отсутствию результата, даже если значения одинаковы.
Проверяются конечность координат, положительная площадь и границы страницы.

## Проверка на реальном PDF

На странице 3 локального `worldbank-srilanka-procurement-plan.pdf` обнаружена
одна таблица. Точное сопоставление строки Individual consultants и столбца
Contracts/Processes Subject to Prior Review возвращает нужную ячейку отдельно
от строки фирм. Полная страница отрендерена Poppler и визуально просмотрена.
Результат с текстом и координатами сохранён локально:
`evals/real/reports/geometry-2026-10-18-srilanka.json` (не в Git).
Это smoke test одной страницы, не новый benchmark accuracy.

```powershell
uv run --extra tables python scripts/inspect_pdf_tables.py `
  evals/real/documents/worldbank-srilanka-procurement-plan.pdf `
  --pages 3 --row-label "Individual consultants" `
  --column-header "Contracts/Processes Subject to Prior Review" `
  --output evals/real/reports/geometry-new-run.json
```

Существующий отчёт не перезаписывается. Отчёты содержат извлечённый текст;
хранить локально в игнорируемом каталоге, проверять перед публикацией.
Дополнительная зависимость устанавливается только с `--extra tables`.

## Что ещё не сделано

- Нет подключения к API, БД, ingestion, retrieval или интерфейсу.
- Нет автоматического выбора row/column по произвольному вопросу.
- Нет OCR таблиц, восстановления безлинейных таблиц и переноса между страницами.
- Не поддержаны сложные/многострочные иерархии заголовков и наследование merged cells.
- Не выполняется автоматическая перепроверка старых документов; текущие индексы сохранены.

Следующий шаг: отдельный формат table evidence с source hash/версией extraction,
сохранением ячеек и трёх bbox; затем изолированный ingestion и проверка подсветки
перед включением в обычный QA. Нельзя подменять старые char offsets координатами
или вставлять синтетический текст таблиц в обычные цитаты без provenance.
