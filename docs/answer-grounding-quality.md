# Качество ответов и цитат: проверяемые гарантии

## Что изменено

Модель выбирает фрагмент, но не получает право незаметно переписать факт.
Сервер находит цитату в конкретном retrieved chunk, восстанавливает полное
предложение и вычисляет страницу и символьные координаты из исходного текста.
Итоговый ответ использует формулировку источника, включая отрицания и оговорки.
Это относится и к ответам опциональных LLM-провайдеров: название провайдера
показывает способ выбора evidence, а не гарантию качества модели.

- Числа, которых нет в цитируемом предложении, приводят к отклонению утверждения.
- Непроверенный пересказ, включая подменённую валюту, не выводится: вместо него
  показывается оригинальное предложение. Это не классификатор всех валютных ошибок.
- Проверяется тема вопроса; для сроков требуется дата или относительный период.
- Подача заявки и поставка различаются в поддержанных формулировках.
- Перенос строки не обрывает предложение перед суммой или датой.
- Длинное предложение не обрезается произвольно: фрагменты более 2000 символов
  отклоняются. Повторные цитаты одного диапазона убираются.

## Измерение

Evaluator v2 добавляет совпадение страницы **и** нужного текста в одном evidence,
span Hit@5/MRR, долю ошибочных отказов и совместную проверку ответа с цитатой.
`expected_answers` — список обязательных буквальных фактов, не альтернатив.
Без этой разметки accuracy ответа равна `null`, а не условным 100%.
Все цитаты ответа должны удовлетворять gold; это консервативная метрика,
которая пока не поддерживает распределённое по нескольким страницам доказательство.

Пустой retrieval остаётся в знаменателе сравнения reranker. Сбой HTTP прерывает
прогон: частичный успешный отчёт не публикуется. Отчёт содержит время измерения,
хеш manifest и параметры запуска. Gate отклоняет неконечные, неверного типа
и неполные обязательные показатели. Старые отчёты v1 сохраняются как история,
но не являются достаточным основанием для нового допуска.

`reranker_gate_passed` означает только прохождение retrieval-порогов.
`enable_reranker_by_default` остаётся false: этот evaluator ещё не сравнивает
полные baseline/candidate QA-пайплайны. Минимальный answer_joint_accuracy — 0.8
по умолчанию, настраивается в baseline gate; отсутствие answer gold блокирует gate.

## Проверка и ограничения

Локальный прогон: 137 тестов прошли, покрытие 85,58%; ruff, formatter и mypy
успешны. Есть предупреждение зависимости Starlette о deprecated httpx TestClient.
Live API/PDF E2E в этот прогон не входит.

Добавлены регрессии: неправильное число, потеря отрицания, подмена валюты,
посторонняя цитата, пустое значение срока, submission против delivery,
неправильная страница, правильная страница без нужного текста, лишнее число
в ответе, отсутствующий gold и NaN/Infinity в отчёте.

Это тесты разработки, **не независимый holdout**. Исторические реальные метрики
не пересчитывались и не изменялись. Новая точность на реальных PDF не заявляется.
Проверка темы эвристическая: не доказывает логическую связь, применимость даты
к нужной строке таблицы или полноту ответа. Исключения в соседнем предложении,
конфликтующие редакции и OCR-ошибки всё ещё требуют отдельной работы.

Следующий шаг: независимо разметить реальные ответы; добавить сложные таблицы,
повторяющиеся значения и конфликтующие сроки; прогнать API baseline/candidate
с фиксацией модели, версии кода и настроек. OCR оценивать отдельно по CER/WER,
не путать успешный запуск OCR с правильностью распознанного текста.

Команды: `uv run pytest -q`, `uv run ruff check src scripts tests`,
`uv run ruff format --check src scripts tests`, `uv run mypy src`.
