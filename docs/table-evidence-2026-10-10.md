# Табличные ответы: ограниченный первый шаг

## Реализовано

Для денежных вопросов добавлен выбор строки в двухколоночных таблицах,
сохранённых в извлечённом тексте с разделителями `|` или tab. Поддержаны
явные заголовки Item/Description/Наименование/Позиция и Cost/Price/Amount/
Стоимость/Цена/Сумма. Название строки должно точно присутствовать в вопросе.
Это не семантический поиск названий и не восстановление структуры PDF.

Цитата содержит оригинальную строку, offsets вычисляются из исходного chunk.
Несовпадение строки, разные найденные строки, повреждённое значение или
неподдерживаемое число столбцов приводят к отказу с пояснением RU/EN.
Проверка применяется и к черновикам LLM: цитата с такой же суммой из соседней
строки не принимается. Валюта из заголовка не приписывается тексту ответа.

Для обычного выбора evidence добавлены проверки категории консультантов и
наличия условия prior review, если оно прямо запрошено. Это эвристика,
не доказательство правильной связи ячеек и не полный семантический анализ.

## Эксперимент и отклонённый вариант

Общий запрет на flattened tables по словам заголовка был проверен 9 октября:
совместная точность цитат упала с 12/19 до 11/19, ошибочные отказы выросли
с 4/19 до 6/19. Этот запрет удалён: он блокировал и правильный ответ.
Одна проверка категории консультантов тоже была недостаточна: вместо Works
сервис выбирал список консультантов без нужного условия. Добавлен тест на этот случай.

Те же 7 PDF и 26 вопросов, сохранённый августовский текст/индекс. API пересобран
из текущих изменений поверх `10e9906`. OCR заново не запускался.

Вопрос `srilanka-consultant-prior-review` теперь получает отказ вместо неправильной

174 теста прошли; покрытие 86,53%. Ruff, formatter, mypy прошли. Есть прежнее

## Осталось

Главный незавершённый пункт — восстановление строк/столбцов из координат PDF
и сохранение этой структуры при чанкинге. Текущий extractor не гарантирует
разделителей, поэтому новая поддержка явных таблиц имеет ограниченное применение.
Многострочные/объединённые ячейки, перенос таблицы на другую страницу,
суммы с повреждёнными OCR цифрами и конфликты валют ещё не решены.
Старые PDF пользователей и исходная разметка не изменялись. Gate остаётся закрыт.
