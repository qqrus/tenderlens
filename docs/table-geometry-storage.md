# Сохранение геометрии таблиц — 19 октября 2026

## Контракт

В `documents.table_geometry` (nullable JSON) сохраняется отдельный snapshot:
версия схемы, SHA-256 исходного PDF, версия pdfplumber и алгоритма, статус,
размер страницы, номер страницы, текст и bbox каждой ячейки.
Координаты — PDF points от верхнего левого угла. Они не заменяют char offsets.

`GET /api/v1/documents/{id}/tables` возвращает snapshot. Чужой source hash
отклоняется с 409; отсутствующий документ — 404. Старые записи с NULL возвращают
`not_processed`. Этот метод не инициирует обработку и не записывает данные.

Состояния: `disabled`, `unsupported` (OCR/mixed), `page_limit`, `ready`, `failed`.
`ready` с пустым массивом означает, что детектор отработал, но таблиц не нашёл.
Это не гарантия отсутствия таблиц в PDF. Рамки и информационные блоки также могут
попадать в кандидаты: они ещё не прошли семантическую проверку.

## Включение

По умолчанию выключено. Для новых native PDF:

```dotenv
TABLE_GEOMETRY_ENABLED=true
TABLE_GEOMETRY_MAX_PAGES=20
```

Локально нужны `uv sync --extra tables` и `uv run alembic upgrade head`.
Docker устанавливает tables extra и применяет миграцию при старте API.
При повторной загрузке уже известного SHA-256 snapshot не пересчитывается.
Ошибки дополнительного извлечения не отменяют успешное извлечение текста;
в лог попадает код события и document_id, но не исключение с текстом документа.
Обработка вынесена из event loop в thread. Лимит страниц не заменяет таймаут
или ограничение памяти: отдельная изоляция тяжёлого парсинга пока не реализована.

## Проверено

- SQLite integration: настоящий tracked синтетический PDF, реальный pdfplumber,
  сервис загрузки, сохранение и чтение JSON, проверка границ и дедупликации.
- API contract: ready с координатами, старые записи, неверный hash, отсутствующий ID.
- Отказы обогащения, отключённая функция, OCR/mixed и лимит страниц.
- В рабочем PostgreSQL применена миграция `20261019_0005`, readiness OK.
- Повторная загрузка существующего синтетического PDF дала deduplicated=true
  и tables.status=not_processed: старый документ не перерабатывался.
- Страница синтетического PDF отрендерена Poppler и визуально просмотрена.

В локальном контейнере флаг включён для проверки новых загрузок. `.env` не изменён;
при запуске без переменной окружения значение снова берётся из конфигурации.
Текущие рабочие порты остаются 5174/8000/5433, другие проекты не затрагивались.

## Граница этапа

QA, retrieval и фронтенд пока НЕ используют snapshot. Не заявляется улучшение
точности ответов или новая геометрическая подсветка. Следом нужны выбор нужной
ячейки по вопросу, отдельный тип геометрической цитаты с тремя bbox и UI overlay,
затем изолированный повторный ingestion/evaluation. Миграция вниз удаляет колонку
snapshot; её не запускали на рабочей базе.
