## Приоритетные проблемы

P0 — риск неправильного источника/ложного допуска модели. P1 — релизная корректность.
P2 — удобство и завершённость. «Код» означает найденный путь ошибки без отдельного
полного runtime-теста; такие пункты нельзя выдавать за воспроизведённые инциденты.

| Приоритет / доказательство | Проблема и код | Приёмочная проверка |
|---|---|---|
| P0 / воспроизведено в браузере | `FileSessionContext.tsx` хранит один objectUrl без documentId; `WorkspacePage.tsx` предпочитает его серверному PDF | Загрузить A → домой → открыть B: запрос B/file и именно B на canvas; refresh/deep link |
| P0 / код | `qa/service.py`: существование quote в chunk не доказывает правильность текста claim | Существующая цитата + подменённое число/дата не принимаются как подтверждённый ответ |
| P0 / код | `evaluation/quality_gate.py`: нестрогие dict/float, NaN ломает смысл сравнений, решение не связано с моделью/config | NaN/Inf, пропуски, чужая версия, неполная выборка дают fail closed |
| P1 / код | `scripts/evaluate_real.py`: поиск оценивается по странице; quote допускает любой gold fragment; page/quote могут сойтись у разных citations | Wrong fact на правильной странице — ошибка; страница+факт+цитата проверяются совместно |
| P1 / код | При отсутствии кандидатов часть reranker-метрик не пополняется; общий знаменатель может отличаться | Все answerable вопросы входят в обе выборки, пустой retrieval не исчезает |
| P1 / код | `ingestion/extractor.py` OCR возвращает plain text, без координат | На скане выделяется реальное место по bbox, либо честный fallback без выделения |
| P1 / код | `CitationDrawer.tsx` передаёт quote и при переключении страницы; text-run matching неоднозначен | Нельзя подсветить тот же текст на чужой странице; повторяющиеся фразы различаются |
| P1 / код | `PdfViewer.tsx`: mount-only ResizeObserver может не получить frame при асинхронном источнике | Поздняя загрузка PDF, resize/zoom и mobile без неверной ширины |
| P1 / код | `ready` извлечения превращается в «анализ завершён»; зависимость workspace от успешного analysis | Анализ loading/failed отличен от готовности PDF; QA доступен при сбое analysis |
| P1 / код | Четыре категории, regex; deadline недостаточно типизирован; severity зависит от категории | Дата заявки не подменяется поставкой; penalty-present не означает high-risk автоматически |
| P1 / код | In-process BackgroundTasks, нет полноценного retry/recovery; failed duplicate остаётся failed | Перезапуск, повтор сбоя и дубликат завершаются контролируемо, не зависают |
| P2 / браузер и код | Подписи 7–11 px, декоративная схема занимает главный экран, 3290 строк CSS | Значения читаются без увеличения, рабочая задача видна до декоративного блока |
| P2 / код | Нет delete; история ограничена первыми 100; analysis вычисляется снова; вопросы локальны | Удаление/повтор/сохранение результата; дальнейшая пагинация при необходимости |
| P2 / код | Нет полного управления фокусом в модалке; устаревшие RU/EN ошибки («OCR нет») | Keyboard/Escape/focus return, отсутствие смешения языков и ложных возможностей |
| P2 / код | `frontend/src/data/mlReport.ts` содержит фиксированные synthetic-результаты; real report отдельно | UI читает проверенный versioned report, явно разделяет synthetic и real |

Пути frontend выше относительно `frontend/src/`, backend — `src/tenderlens/`,
если не указан иной префикс. Это аудит ключевых пользовательских цепочек, не исчерпывающий
security audit и не доказательство отсутствия других багов.

## На чём сейчас построен интеллект

По defaults в `core/config.py`: embeddings —
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, поиск dense+lexical,
ответы — **extractive**. Это извлечение фрагментов с правилами, а не работа GPT
по умолчанию. Провайдеры Ollama/OpenAI реализованы как опции; наличие
`qwen3:4b` в конфигурации не означает, что модель запущена. Runtime настройки
работающего backend сегодня не подтверждались — Docker выключен.

Обученный local reranker переупорядочивает найденные фрагменты, но сам не пишет
ответ. Замена генератора не исправит неверный PDF, потерю таблицы, неоднозначную дату
или нечестный evaluator. Поэтому новый план начинает с этих границ и baseline.

## Что говорят сохранённые ML-результаты

Источник: `evals/real/result_v1.json`, **эксперимент 2026-08-24, сегодня не повторялся**.

| Метрика | Baseline | Reranker |
|---|---:|---:|
| Попадание нужной страницы на первом месте | 73.68% | 89.47% |
| Попадание страницы в первых пяти | 100% | 100% |
| MRR | 0.8553 | 0.9386 |

У ответов в том же отчёте: citation page accuracy **42.11%**, quote accuracy **36.84%**.
Это не две end-to-end колонки baseline/candidate: отдельного доказательства улучшения
финальных ответов reranker этим сравнением нет. Решение отчёта правильно оставляет
`enable_reranker_by_default=false`.

Holdout: 5 исходных англоязычных procurement plans World Bank + 2 производных OCR,
26 вопросов (19 answerable, 7 unanswerable). Семь файлов — не семь независимых источников.
Такой набор полезен, но не представляет реальные русскоязычные тендеры и весь спектр PDF.
`ocr_success_rate=1` означает успешную обработку по текущей проверке, не 100% распознавания:
CER/WER и геометрия цитат не измерены. Записи privacy review существуют, но независимую
ручную проверку всех страниц/разметки нельзя подтвердить одним флагом в manifest.

Поскольку ошибки этого holdout уже изучались, при доработках по ним его следует
использовать как regression. Для независимого выпуска нужен новый небольшой lockbox.
Не менять старые цифры и не сравнивать старый page-only Hit с новым span-aware Hit
как одну шкалу. Новые пороги и версию evaluator зафиксировать до просмотра lockbox.

## Дизайн: два направления, не два новых приложения

**A — документный стол.** Светлый нейтральный фон, зелёный акцент, небольшая постоянная
навигация. Слева условия, справа белая страница. Рекомендован для длительного чтения
и презентации преподавателю: визуальный вес у даты/суммы/источника, не у украшений.

**B — аналитический кабинет.** Графит, приглушённый мятный акцент, горизонтальная
навигация. PDF слева, выводы справа. Подойдёт, если важнее сохранить тёмный характер
продукта. Не просто перекрашенный A: другая организация рабочего места.

Макеты: [A](design/reference-a.html), [B](design/reference-b.html).
Скриншоты: [A](design/reference-a.png), [B](design/reference-b.png).
Открываются локально без установки зависимостей. Работают переключение вкладок,
клавиатура и переход к трём примерам цитат. Другие подписи навигации — только композиция.
Все факты вымышленные, страница сверстана HTML, это не доказательство исправления
настоящей PDF-подсветки. Дизайн приложения до выбора пользователя не менялся.

Главная в выбранном направлении должна стать библиотекой документов: одна заметная
загрузка, небольшой демонстрационный сценарий, история со статусами. На рабочем
экране — результат и источник. ML-графики живут на отдельной странице экспериментов,
а не отнимают место у анализа документа.

## Решение о завершении

Пора прекращать расширение архитектуры и собирать ограниченный v1.0. ML-портфолио
выиграет от честного воспроизводимого сравнения и разбора ошибок больше, чем от новой
модели без проверки. Универсальный PDF оставить последним небольшим функциональным
шагом: общий Q&A и summary, не универсальная юридическая/отраслевая экспертиза.
